# ROB Improvements
* Author: Rainer (Oskar) Brell
* Latest Version: Please check the NVDA Add-on Store

This add-on enhances applications with new features and provides global support.

## Windows Explorer

1.  **Enhanced Braille Display Information:**
    From now on, the braille display in Explorer will show not just the selected file name or folder, but **all column information**. This significantly improves clarity and allows you to read all relevant details directly.
2.  **Optional Speech Output for Column Information:**
    If you wish to hear this additional information via speech output, you can easily configure it: In the NVDA menu, under **Options > Settings > "ROB Improvements"**, you will find the corresponding setting to activate this function.
3.  **Correction for Renaming Files/Folders (F2):**
    Another frequently requested correction concerns renaming files and folders. When you press F2 in Explorer to rename an entry, the input field label will no longer incorrectly be the file name, but correctly display the word **"Rename"**. This increases clarity and prevents misunderstandings.

## Markdown

When a Markdown file (*.md) is selected in Windows Explorer or Total Commander:

*   NVDA+Alt+Space displays the file in the NVDA browser.
*   NVDA+Alt+Shift+Space saves the file in HTML format.

## In All Browsers

*   Ctrl+NVDA+F4 displays the page URL; pressing it twice copies it to the clipboard.

## Microsoft Outlook (Version 2013 and later)

*   Empty folders are usually recognized.
*   Ctrl+Alt+J jumps to the first folder below the Inbox that contains unread emails.
*   Shift+Ctrl+Alt+I saves the current folder as Folder 1.
*   Shift+Alt+I jumps to Folder 1.

Four additional folders can be defined and jumped to. These folders can also be in a different account. The key gestures for these are still freely assignable.
